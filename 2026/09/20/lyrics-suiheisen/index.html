前言

文法解析

  • 出来(でき)るだけ：盡可能的
  • （V./Adj.）～ように：為了…
  • （N.）～のように：像…一樣
  • 〜い -> 〜さ：把形容詞變成名詞
    • 高い（高） -> 高さ（高度）
    • 重い（重） -> 重さ（重量）
    • 長い（長） -> 長さ（長度）
    • 美しい（美） -> 美しさ（美麗）
  • ～ながら：一邊…
  • いつしか： 不知不覺間、不知從何時起
  • ～のだから：因為～
  • ～ず / 〜ず（に）：
    • 〜ず：相當於「なくて」 表並列或原因理由
    • 〜ず（に）：相當於「ないで」 表手段、附帶狀況（沒有做〜就〜）
  • ～といい：～就好了、應該要～
  • 內容/想法/說的話 + と + 說/想/叫/寫
  • ～ほど： 表示程度
  • いくつ (幾つ)：幾個
  • 數量詞 + も：數量很多
