歌詞翻譯：羊文学 - 光るとき

發表於2026-08-23|更新於2026-08-27|語言學習
|總字數:1.1k|閱讀時間:3分鐘|瀏覽量:

前言

新的系列開始囉！希望這次我可以堅持久一點（之前的極短篇只做兩篇 XD）。這次想做的是日文歌詞翻譯，主要想做的原因是我很喜歡聽歌，在聽的時候也會想知道他唱什麼；同時我也有學過一點基礎的日文，但很久沒複習了，想說透過這種方式來學習應該也不錯。第一篇想翻譯的歌詞是羊文学的光るとき，這首歌是日劇《平家物語》的主題曲，也是一首意境很美的歌。羊文學是我很喜歡的樂團，他們的歌詞都非常有文學感，也是我在聽這首歌的時候想到翻譯學習的這個 Idea。

歌詞翻譯

羊文学 - 光るとき
羊文學 - 閃耀之時

あの花（はな）が咲（さ）いたのは そこに種（たね）が落（お）ちたからで
那朵花之所以會綻放 是因為種子落在了那裡

いつかまた枯（か）れた後（あど）で種（たね）になって続（つづ）いてく
等到枯萎的那一天 會變為種子延續下去

君（きみ）たちの足跡（あしあと）は 進（すす）むたび変（か）わってゆくのに
你們的足跡　明明隨著前進而不斷改變

永遠（えいえん）に見（み）えるものに苦（くる）しんでばかりだね
卻永遠為了那些看得到的事物而感到痛苦呢

荒野（こうや）を駆（か）ける この両足（りょうあし）で
用這雙腳在荒野上奔跑

ゴーイング ゴーイング それだけなんだ
Going Going 僅此而已

明日（あす）へ旅立（たびだ）つ準備（じゅんび）はいいかい
準備好向明天出發了嗎

そこで戸惑（とまど）う でも運命（うんめい）が
儘管會迷惘 但是命運正

コーリング コーリング 呼（よ）んでいる
Calling Calling 在呼喚我

ならば 全（すべ）てを生（い）きてやれ
那麼就用盡全力去活完這一生吧

何回（なんかい）だって言（い）うよ 世界（せかい）は美（うつく）しいよ
無論多少次我都會告訴你 世界是美麗的喔

君（きみ）がそれを諦（あきら）めないからだよ
因為你從未放棄過它啊

最終回（さいしゅうかい）のストーリーは初（はじ）めから決（き）まっていたとしても
即便最終章的故事 從一開始就已經決定好了

今（いま）だけはここにあるよ 君（きみ）のまま光（ひか）ってゆけよ
但唯有此刻 就在這裡 請保持著原本的樣子閃耀下去吧

あの花（はな）が落（お）ちるとき その役目（やくめ）を知（し）らなくても
當那朵花凋零的時候 儘管不知道它的使命

側（そば）にいた人（ひと）はきっと分（わ）かっているはずだから
在它身旁的人也一定能夠理解的吧

海風（うみかぜ）を切（き）る 胸（むね）いっぱいに
颳起了海風 心中百感交集的

ゴーイング ゴーイング 息（いき）をするんだ
Going Going 呼吸著

今日（きょう）を旅立（たびだ）つ準備（じゅんび）はいいかい
準備好在今天出發了嗎

ときに戸惑（とまど）う 繰（く）り返（かえ）すんだ
偶爾會感到迷惘 但要不斷重複著

コーリング コーリング 聞（き）こえてる
Calling Calling 聽得見嗎？

ならば 全（すべ）てを生（い）きてやる
那麼我會用盡全力的去活完這一生

何回（なんかい）だって言（い）うよ 世界（せかい）は美（うつく）しいよ
無論多少次我都會告訴你 世界是美麗的喔

君（きみ）がそれを諦（あきら）めないからだよ
因為你從未放棄過它啊

混沌（こんとん）の時代（じだい）に 泥（どろ）だらけの君（きみ）のままで輝（かがや）きを見（み）つめていて
在混沌的時代裡 注視著充滿泥濘的你的光輝

悲（かな）しみに向（む）かう夜（よる）も 揺（ゆ）るがずに光（ひか）っていてよ
即使在面對悲傷的夜晚 也毫不動搖地持續閃耀吧

いつか巡（めぐ）ってまた会（あ）おうよ
總有一天讓我們再次相遇吧

最終回（さいしゅうかい）のその後（あと）も
在最終回的那之後

誰（だれ）かが君（きみ）と生（い）きた記憶（きおく）を語（かた）り継（つ）ぐでしょう
某人會把與你一同生活的記憶給傳承下去的吧

いつか笑（わら）ってまた会（あ）おうよ
總有一天讓我們笑著再次相遇吧

永遠（えいえん）なんてないとしたら
如果說永遠這種東西不存在的話

この最悪（さいあく）な時代（じだい）もきっと続（つづ）かないでしょう
這個最糟糕的時代也持續不下去的吧

君（きみ）たちはありあまる奇跡（きせき）を
你們正帶著無數的奇蹟

駆（か）け抜（ぬ）けて今（いま）をゆく
奔向今天

文法解析

  • ～のは、～からで：之所以…是因為…
  • ～たび：每當…的時候
  • ～てゆく：狀態的持續/變化
  • ～のに：逆接/轉折
  • ～てばかりだ：總是…/只會…
  • ～てやれ：命令/意志
  • ～だって：無論…都/即使…
  • ～としても：即便…也/就算…也
  • ～のまま：保持著…的狀態
  • ～てゆけよ：去…吧/漸漸地…下去吧
  • ～はず：理應、應該、肯定
  • ～だらけ：滿是…、全是…
  • ～なんて：之類的、之類的這種事
  • ～としたら：如果…的話
