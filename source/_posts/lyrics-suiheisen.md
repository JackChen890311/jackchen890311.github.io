# 前言
第二篇日文翻譯來了！這次要翻譯的是 Back Number 的水平線，據說是 Back Number 原本要在全日本高中運動會上開場，但遇到 2020 Covid 疫情而中止，主唱便創作了這首歌為選手們打氣，鼓勵選手們從悲傷中站起來繼續努力。印象中第一次聽到是在國外，就被旋律給吸引了，後來才知道是一首這麼溫柔的歌。

# 文法解析
- {% ruby 出来 でき %}るだけ：盡可能的
- （V./Adj.）～ように：為了...
- （N.）～のように：像...一樣
- 〜い -> 〜さ：把形容詞變成名詞
  - 高い（高） -> 高さ（高度）
  - 重い（重） -> 重さ（重量）
  - 長い（長） -> 長さ（長度）
  - 美しい（美） -> 美しさ（美麗）
- ～ながら：一邊...
- いつしか： 不知不覺間、不知從何時起
- ～のだから：因為～
- ～ず / 〜ず（に）：
  - 〜ず：相當於「なくて」 表並列或原因理由
  - 〜ず（に）：相當於「ないで」 表手段、附帶狀況（沒有做〜就〜）
- ～といい：～就好了、應該要～
- 內容/想法/說的話 + と + 說/想/叫/寫
- ～ほど： 表示程度
- {% ruby 幾 いく %}つ：幾個
- 數量詞 + も：數量很多
